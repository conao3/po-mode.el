* Overview

This repository provides ~po-mode.el~ packaged for modern Emacs package managers.

~po-mode~ is a major mode for editing GNU gettext PO files, which are used for internationalization (i18n) and localization of software. It provides translators with a powerful editing environment specifically designed for working with translation files.

The files included here are sourced from GNU gettext (version 0.19.8.1) and are distributed under the GPLv3 license.

* Features

- Dedicated major mode for PO file editing
- Navigate between translated and untranslated entries
- Edit msgstr entries with proper handling of special characters
- Support for plural forms in translations
- Automatic detection of file encoding
- Integration with gettext toolchain

* Installation

** Using leaf (recommended)

#+begin_src emacs-lisp
(leaf po-mode
  :ensure t
  :mode ("\\.po\\'" . po-mode))
#+end_src

** Using use-package

#+begin_src emacs-lisp
(use-package po-mode
  :ensure t
  :mode ("\\.po\\'" . po-mode))
#+end_src

** Manual installation

Add the following to your init file:

#+begin_src emacs-lisp
(autoload 'po-mode "po-mode"
          "Major mode for translators to edit PO files" t)
(setq auto-mode-alist (cons '("\\.po\\'\\|\\.po\\." . po-mode)
                            auto-mode-alist))

;; For automatic encoding detection
(autoload 'po-find-file-coding-system "po-compat")
(modify-coding-system-alist 'file "\\.po\\'\\|\\.po\\."
                            'po-find-file-coding-system)
#+end_src

* Basic Usage

When visiting a PO file, ~po-mode~ activates automatically. Key bindings include:

| Key       | Description                              |
|-----------+------------------------------------------|
| =RET=     | Edit the current entry                   |
| =n= / =p= | Move to next/previous entry              |
| =u=       | Move to next untranslated entry          |
| =f=       | Move to next fuzzy entry                 |
| =k=       | Kill the current entry's translation     |
| =w=       | Copy msgid to the kill ring              |
| =V=       | Validate the PO file                     |
| =?=       | Display help                             |
